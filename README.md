# problem-decomposer

把模糊的問題變精確。

## 為什麼做這個

很多問題問不清楚。問題裡每個詞都有不同的解讀空間，這才是問題的根源。

問題模糊，解法就會亂猜。在回答「怎麼做」之前，先把問題拆清楚，才不會做了一堆事情，結果方向錯了。

這個技能包記錄了一套從真實案例反覆驗證出來的方法：逐詞確認。四個版本迭代，每次都靠新案例挖出更深的盲點。

## 它能做什麼

- 把模糊問題拆成逐詞清單，讓對方或自己確認每個詞的具體定義
- 從情緒性表達（煩、累、不會）追問出具體數字和情境
- 用四關卡輔助框架做最後檢查（目標/自己會不會/值不值得/卡在哪）
- 判斷任務適合 AI 還是傳統軟體（核心標準：有沒有模糊語意需要處理）
- 三種使用場景：自己問問題前先拆、幫別人釐清需求、做成 AI 提問機器人

## 它不做什麼

- 不直接回答問題（拆清楚之後，你自己決定怎麼做）
- 不套固定公式（逐詞確認比套框架更底層，框架只是輔助）
- 不替代領域判斷（知道問題在哪，但解法還是得靠你）

## 安裝

把整個資料夾複製到你的技能包目錄：

```
~/.claude/skills/problem-decomposer/
```

讓 AI 讀 `SKILL.md` 就能啟用。案例在 `references/examples.md`，版本歷史與隱性知識提煉模式在 `references/changelog.md`。
